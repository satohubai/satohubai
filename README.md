We map the onchain agent stack, score it on evidence, and give builders the tools to ship agents that actually move onchain — with humans and the chain kept in the loop the whole way.

### What we ship

| | | |
|---|---|---|
| 🛠️ **Builder** | Build any crypto agent from a mapped library of skills, MCPs, tools, wallets, payment rails, and frameworks. | [satohub.ai/build](https://satohub.ai/build) |
| 🗂️ **The Index** | The scored, daily-updated index of the onchain agent stack — every framework, MCP, wallet, and rail, tracked and scored. | [`onchain-agents`](https://github.com/satohubai/onchain-agents) |
| 🔌 **MCP** | Point your agent at the live directory — 12 read-only tools over Streamable HTTP. | [satohub.ai/mcp](https://satohub.ai/mcp) |
| 🖥️ **Sato OS** | Self-hosted control plane: spin up an agent, fund it, task it, and watch it work — every action verified against the chain. Your keys never leave your machine. | [satohub.ai/os](https://satohub.ai/os) |
| ⬡ **Passport** | On-chain agent identity + a verifiable track record, readable by anyone. | [satohub.ai/agents](https://satohub.ai/agents) |
| ⬡ **Sato Score** | A 0–100 score of how open, active, and verifiable a project is — evidence only, never a safety or profit grade. | [satohub.ai/sato-score](https://satohub.ai/sato-score) |

### How we work

- **Evidence, not vibes.** Nothing is called profitable, safe, audited, or verified unless the evidence supports it. Self-reported ≠ verified.
- **Built on Base & Ethereum.** ERC-8004 identity, Basenames, x402 payments, EAS attestations — the current standards, live onchain.
- **Chain as referee.** In Sato OS, every execution is checked against its on-chain receipt; humans hold the veto, freeze, and kill switch.
